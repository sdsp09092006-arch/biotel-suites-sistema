# 🏨 Biotel Suites - Sistema de Gestión Hotelera

Sistema web para la automatización del proceso de check-in, check-out y gestión integral de la recepción del hotel **Biotel Suites**.

---

## 📋 Descripción del Proyecto

La Gerencia de Recepción del hotel Biotel Suites opera actualmente con hojas de cálculo en Excel, registros en papel y comunicación por radio, lo que genera:

- ⏱️ Check-in promedio de **18 minutos**
- ⏱️ Check-out promedio de **15 minutos**
- 📋 Duplicidad de registros (Excel + libro físico)
- 🚫 Falta de integración entre departamentos

**Este sistema busca reducir los tiempos a 3-5 minutos** mediante la digitalización completa del proceso.

---

## 🛠️ Tecnologías Utilizadas

### Frontend
- **HTML5** semántico
- **CSS3** (variables, Flexbox, Grid, responsive)
- **JavaScript** ligero (modales, toasts, validaciones)

### Backend (futuro)
- **PHP** 8.x
- **MySQL** (vía XAMPP)

### Control de versiones
- **Git + GitHub**
